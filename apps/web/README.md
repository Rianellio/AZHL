# apps/web

AZHL's public site — the only app with real business logic in Phase 1 (League Hub: Home,
Standings, Schedule, Game Center, News).

Not deployed yet. `vercel.json` here declares this as the deployable unit (Vercel project root
directory = `apps/web`) for when the team is ready to connect a Vercel account — see
[`.claude/future-services.md`](../../.claude/future-services.md). No live deployment or
credentials exist today.

See [`.claude/architecture.md`](../../.claude/architecture.md) for the services→RSC/API-route
pattern this app follows.
